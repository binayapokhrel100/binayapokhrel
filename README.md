<h2 align="center">🏠 Connecticut Real Estate Sales Analysis</h2>

<div align="center">

<img
  src="https://img.shields.io/badge/Oracle-SQL-F80000?style=for-the-badge&logo=oracle&logoColor=white"

/>

</div>

<br/>

<p>
Analyzed the <b>2021–2023 Connecticut real estate sales dataset</b>
using <b>Oracle SQL Developer</b>
to evaluate property pricing trends and annual sales activity.
</p>

<h3>🎯 Project Objectives</h3>

<ul>

<li>Analyze annual property sales activity</li>

<li>Compare different property categories</li>

<li>Calculate average sale prices</li>

<li>Identify highest sale values</li>

<li>Identify lowest and highest average property prices</li>

<li>Evaluate pricing trends</li>

<li>Create structured SQL reports</li>

<li>Support comparative property-market analysis</li>

</ul>

<h3>🛠️ SQL Concepts Used</h3>

```sql
AVG()
COUNT()
MAX()
GROUP BY
ORDER BY
UNION
CREATE VIEW
SELECT
WHERE
```

<h3>📊 Example SQL Query</h3>

```sql
SELECT
    property_type,
    COUNT(*) AS total_sales,
    AVG(sale_amount) AS average_sale_price,
    MAX(sale_amount) AS highest_sale
FROM real_estate_sales
GROUP BY property_type
ORDER BY average_sale_price DESC;
```
